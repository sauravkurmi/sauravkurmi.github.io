Channel Factory

A private desktop tool for publishing animated videos to the owner's own YouTube channels.

What it does

  • Uploads videos that the owner made to the owner's own YouTube channels, as private or scheduled uploads.
  • Sets titles, descriptions and tags on those videos.
  • Reads view statistics (views, watch time, subscribers gained) for those channels, so the owner can see which videos work.

Who can use it

Channel Factory is not a public service. Nobody can sign up for it. It runs only on its owner's own computer, and it signs in only to YouTube channels that the owner manages. Every sign-in uses Google's standard OAuth consent screen, and access can be removed at any time from Google Account → Third-party access.

How it uses Google data

Channel Factory uses the YouTube Data API and the YouTube Analytics API. It keeps sign-in tokens only on the owner's computer, never sends YouTube data to any other server, and never sells or shares it. Full details are in the Privacy Policy. By using Channel Factory you agree to the YouTube Terms of Service.
